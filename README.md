# Ecoevan · 个人名片

一个单文件的个人名片 / 在线简历：首页、关于我、详情（故事 / 作品集 / 简历）、他人评价、联系我。

- `index.html` — 站点入口（GitHub Pages 默认打开的文件）
- `evan-personal-site.html` — 同一份文件的备份名，方便本地直接打开
- `avatar.jpg` — 头像原图（页面里的头像已内嵌，这个文件只是备份）

## 他人评价：从“仅本机”切到“所有人可见”

默认状态下，评论存在访客浏览器的 `localStorage` 里，只有自己看得到。
要变成**所有人可见、免登录**，用 Supabase（免费额度足够个人站点）：

### 1. 建项目

1. 注册 <https://supabase.com>，新建项目（区域选 Singapore / Tokyo 更快）
2. 打开左侧 **SQL Editor**，粘贴执行：

```sql
create table if not exists public.reviews (
  id         bigint generated by default as identity primary key,
  relation   text not null check (char_length(relation) between 1 and 20),
  nickname   text check (nickname is null or char_length(nickname) between 1 and 20),
  content    text not null check (char_length(content) between 1 and 500),
  created_at timestamptz not null default now()
);

alter table public.reviews enable row level security;

-- 任何人可读
create policy "reviews readable by all"
  on public.reviews for select using (true);

-- 任何人可写，但不能改、不能删
create policy "reviews insertable by all"
  on public.reviews for insert with check (true);
```

### 2. 同域名接口（已配好）

浏览器**不直接访问 supabase.co**（部分地区访问不到），而是请求自己域名下的
`/api/reviews`，由 Cloudflare Pages Function 在服务端转发到 Supabase。

- 函数文件：`functions/api/reviews.js`
- 页面里只需要一行：`var REVIEWS_API = '/api/reviews';`
- Supabase 的 URL / anon key 写在函数里（服务端），不再出现在网页源码中

> 如果以后换了 Supabase 项目或 key，改 `functions/api/reviews.js` 顶部那两行即可。
> 也可以改成在 Cloudflare Pages 的 Environment variables 里配 `SUPABASE_URL` / `SUPABASE_KEY`。

### 3. 部署

推送到 GitHub 后，Cloudflare Pages 会自动构建并生效（约 1 分钟）。验证接口：

```bash
curl https://ecoevan.pages.dev/api/reviews
```

返回 JSON 数组即正常。

### 说明

- `anon` key 本来就是给前端用的公开 key，安全性靠上面两条 RLS 策略（只能读、只能写；不能改删）。
  **不要把 `service_role` key 放进前端。**
- 管理评论：Supabase → **Table Editor → reviews**，可以直接删掉不合适的记录。
- 同一浏览器 1 分钟内只能发一条（前端节流）；要更严的防刷可以在 Supabase 侧加触发器或 Edge Function。
- 免费项目闲置 7 天会暂停，打开一次后台即可唤醒；数据不会丢。

## 自己上传照片（Pages CMS）

不用改代码，也不用来回找人：用 Pages CMS 在网页上拖图即可，保存后自动提交、自动重新部署。

### 第一次配置（约 2 分钟）

1. 打开 <https://app.pagescms.org>
2. **Sign in with GitHub**（用 Evan-1021 账号）
3. 提示安装 GitHub App 时，点 **Install**，只选择 `Ecoevan` 这个仓库
4. 回到页面，选择仓库 `Evan-1021/Ecoevan`

### 以后每次传照片

1. 打开 <https://app.pagescms.org> → 选仓库
2. 左侧点 **图库 / 作品集**
3. **照片列表 → 添加**：选图片（自动存进 `photos/`），可填一句说明
4. 点 **Save** → 自动提交到 GitHub → Cloudflare Pages 约 1 分钟后重新构建
5. 刷新网站：**我的最近 → 图库** 和 **详情 → 作品集** 都会出现

### 相关文件

| 文件 | 作用 |
|---|---|
| `.pages.yml` | 后台能编辑什么（图片目录、字段） |
| `content/gallery.json` | 照片清单（后台自动写） |
| `photos/` | 上传的图片 |

> 想再增加可编辑内容（例如「小日记」），在 `.pages.yml` 的 `content` 里加一段配置即可。
