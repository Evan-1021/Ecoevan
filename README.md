# Ecoevan · 个人名片

一个单文件的个人名片 / 在线简历：首页、关于我、详情（故事 / 作品集 / 简历）、他人评价、联系我。

- `index.html` — 站点入口（GitHub Pages 默认打开的文件）
- `evan-personal-site.html` — 同一份文件的备份名，方便本地直接打开
- `avatar.jpg` — 头像原图（页面里的头像已内嵌，这个文件只是备份）

## 本地预览

直接用浏览器打开 `index.html`。

## 发布（GitHub Pages）

仓库 Settings → Pages → Build and deployment → Deploy from a branch → `main` / `root`，保存后访问：

```
https://evan-1021.github.io/Ecoevan/
```

## 他人评价：从“仅本机”切到“所有人可见”

默认状态下，评论存在访客浏览器的 `localStorage` 里，只有自己看得到。
要变成**所有人可见、免登录**，用 Supabase（免费额度足够个人站点）：

### 1. 建项目

1. 注册 <https://supabase.com>，新建项目（区域选 Singapore / Tokyo 更快）
2. 打开左侧 **SQL Editor**，粘贴执行：

```sql
create table if not exists public.reviews (
  id         bigint generated by default as identity primary key,
  relation   text not null check (char_length(relation) between 1 and 20),
  nickname   text check (nickname is null or char_length(nickname) between 1 and 20),
  content    text not null check (char_length(content) between 1 and 500),
  created_at timestamptz not null default now()
);

alter table public.reviews enable row level security;

-- 任何人可读
create policy "reviews readable by all"
  on public.reviews for select using (true);

-- 任何人可写，但不能改、不能删
create policy "reviews insertable by all"
  on public.reviews for insert with check (true);
```

### 2. 填两行配置

项目 **Settings → API** 里复制 `Project URL` 与 `anon public` key，打开 `index.html`，搜索 `SUPABASE_URL`：

```js
var SUPABASE_URL = 'https://xxxxxxxx.supabase.co';
var SUPABASE_ANON_KEY = 'eyJhbGciOiJIUzI1NiIsInR5cCI6...';
```

两行留空 = 本机模式；填上并刷新 = 云端模式（页面上会自动出现“评论已公开显示”的提示）。

### 3. 提交

```bash
git add -A && git commit -m "connect supabase" && git push
```

### 说明

- `anon` key 本来就是给前端用的公开 key，安全性靠上面两条 RLS 策略（只能读、只能写；不能改删）。
  **不要把 `service_role` key 放进前端。**
- 管理评论：Supabase → **Table Editor → reviews**，可以直接删掉不合适的记录。
- 同一浏览器 1 分钟内只能发一条（前端节流）；要更严的防刷可以在 Supabase 侧加触发器或 Edge Function。
- 免费项目闲置 7 天会暂停，打开一次后台即可唤醒；数据不会丢。
